# Пульс — маркетинговая кампания на React

Демонстрационная маркетинговая кампания для вымышленной платформы автоматизации
малого бизнеса **«Пульс»**. Проект собран как единый сайт: лендинг, интерактивные
форматы (тест, игра, чек-лист), ИИ-чат-ассистент и презентация — всё в одной
фирменной айдентике.

**Живой сайт:** https://qa-novchenkova.github.io/puls/

> Это портфолио-проект. Бренд «Пульс» вымышленный, продукт не настоящий —
> цель показать навык создания маркетингового контента и кода через ИИ-инструменты
> с ручной доработкой (vibe coding).

## Технологии

- **React 19** + **TypeScript** — интерфейс из компонентов с проверкой типов
- **Vite** — сборка и дев-сервер
- **Tailwind CSS 4** — стили через утилиты, дизайн-токены в `src/index.css`
- **React Router** (HashRouter) — навигация между страницами
- **Formspree** — приём заявок с формы (см. ниже)
- **GitHub Pages** + GitHub Actions — хостинг и автодеплой

Вебшрифты намеренно не подключаются (системные стеки) — чтобы не зависеть от CDN
и не ловить «тихий фолбэк». Тёмная и светлая темы — через CSS-переменные с ручным
переключателем.

## Запуск локально

```bash
npm install      # установить зависимости
npm run dev      # дев-сервер (обычно http://localhost:5173/puls/)
npm run build    # production-сборка в dist/

git commit -m "описание правок"

```

Через 1–2 минуты изменения — на https://qa-novchenkova.github.io/puls/

## Форма заявки

Форма на лендинге отправляет заявки через **Formspree** (бесплатный сервис-посредник,
т.к. статический сайт сам не умеет слать письма). Endpoint задаётся одной строкой
в `src/pages/Landing.tsx`:

```ts
const FORMSPREE_ENDPOINT = 'https://formspree.io/f/xxxxxxxx'
```

Если строка пустая — форма работает в демо-режиме (показывает подтверждение, но не шлёт).
Валидация: имя (буквы, 2–40 символов), e-mail (проверка формата), телефон (русская маска
`+7 (900) 000-00-00`), защита от повторной отправки.

## Про ИИ-чат-ассистента

Бот **сценарный** (rule-based): сопоставляет ключевые слова и отвечает по заранее
заданной «базе знаний». Он демонстрирует **логику и интерфейс** ИИ-агента —
ответы по базе знаний (RAG-подход), цепочку действий (заявка → CRM → задача) и
эскалацию на человека, — но не использует настоящую языковую модель.
В боевой версии на его месте была бы полноценная LLM за бэкендом.
