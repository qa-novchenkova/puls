# Пульс — демо-кампания автоматизации малого бизнеса

Портфолио-проект: единая маркетинговая мини-кампания для вымышленной платформы
автоматизации **«Пульс»**. Собрана в парадигме **vibe coding** — контент и код
сгенерированы с помощью ИИ и доведены вручную (дизайн-система, тексты, правки).

🔗 **Живой сайт:** https://qa-novchenkova.github.io/puls/

## Что внутри

- **Лендинг** «Бизнес на автопилоте» — hero с живым «пульс-монитором» (Canvas),
  боль клиента, механика в 3 шага, возможности, метрики, форма заявки.
- **Глоссарий клиента** — интерактивный словарь терминов автоматизации и ИИ
  с поиском и фильтрами.
- *(в работе)* лидмагнит-чек-лист, виральный тест, мини-игра, ИИ-чат-бот, презентация.

## Стек

| Технология | Роль |
|---|---|
| **React 19** | компонентный UI |
| **TypeScript** | типобезопасность |
| **Vite** | сборка и дев-сервер |
| **Tailwind CSS v4** | дизайн-система через утилиты |
| **React Router (Hash)** | навигация без 404 на GitHub Pages |
| **GitHub Actions + Pages** | автодеплой |

## Дизайн

- Сигнатурный мотив — ЭКГ-линия пульса (обыгрывает название).
- Акцент коралл `#FF4B57` (тёмный `#D62B3A` под кнопки — для контраста),
  мятный `#0FA36B` как «готово».
- Светлая и тёмная темы через CSS-переменные + ручной переключатель.
- Адаптив, доступность (focus-visible, `prefers-reduced-motion`).

## Запуск

```bash
npm install      # установить зависимости
npm run dev      # дев-сервер → http://localhost:5173/puls/
npm run build    # сборка в dist/
npm run preview  # посмотреть собранную версию
```

## Деплой

Пуш в ветку `main` автоматически собирает и публикует сайт через GitHub Actions
(workflow `.github/workflows/deploy.yml`). В настройках репозитория:
**Settings → Pages → Source → GitHub Actions**.
